# 启航小店管家

**把返现、补发、补款、退款和推广费，算进每一单。**

面向 2-5 人小电商团队的真实利润工具 · Windows 桌面端

---

## 一、这些账，是不是每个月都在折磨你

| 你遇到的问题 | 实际情况 |
|---|---|
| 月底算利润，算出来和感觉差很多 | 返现、补款、补发都发生在微信里，压根没进账 |
| 不知道哪个链接在亏钱 | 推广费只有一个总数，不知道摊到哪个款上 |
| 退款了，推广费却退不回来 | 退货的成本只算了退款，没算运费、包装和货损 |
| 客服记不住售后花了多少 | 没有地方记，全靠聊天记录翻 |
| 请不起专职财务 | Excel 越做越乱，链接一多就崩 |

平台后台只告诉你卖了多少，不告诉你赚了多少。小店管家就是来补上这一块的。

---

## 二、小店管家怎么帮你

一句话：**客服随手记售后，老板录成本和推广费，订单一导，利润自己算出来。**

| 你的问题 | 小店管家的做法 |
|---|---|
| 售后支出没地方记 | 客服按一个快捷键，10 秒记一笔工单 |
| 推广费不知道摊到哪 | 录入推广费，按链接自动分摊，看链接贡献利润 |
| 成本靠脑记 | 商品档案里填成本价，订单一导自动匹配 |
| 月底对账靠 Excel | 订单 + 工单 + 费用自动汇总成利润表 |
| 客服和老板数据对不上 | 多账号协作，客服记、老板看，同一份数据 |

它不替代你的打单软件，也不要求平台接口，订单用 Excel 导入就能算。

## 三、开始之前，准备四样东西

1. 一台 Windows 电脑。
2. 店铺后台导出的订单表（淘宝/天猫、拼多多、抖店都可以）。
3. 商品的进货成本价。
4. 本月的推广费金额（直通车、千川、多多搜索等）。

没有订单表也能先用：手工建单同样可以算账。

---

## 四、第一次使用：四步搞定

### 第 1 步：安装并登录

下载安装包，装好后打开，注册账号登录。首次登录会让你创建一家店铺，填店铺名称和平台即可。

### 第 2 步：录入商品和成本

进入「商品」，新建商品，填商品名称、规格和成本价。商品多就下载模板，批量导入。

成本价填的是你的进货价，不是售价。后面所有利润都由这个数算出来。

### 第 3 步：导入订单

进入「订单」→「导入」，选择平台导出的 Excel。

第一次导入需要把平台表格的列对应到系统字段，比如"买家实付金额"对应"实付金额"。配好后保存为模板，下个月同样的表一键导入。

导入前会先预览，确认没问题再入库；同一个订单号重复导入不会重复计算。

### 第 4 步：记第一笔工单

进入「工单」→「新建」，或者在任意界面按快捷键唤起速记窗口：

选类型 → 填金额 → 选订单（可以后补）→ 上传凭证（可选）→ 提交。

到这一步，你已经可以出第一张利润表了。

## 五、每天怎么用：客服记工单

售后一发生就记，不要等月底回忆。

### 5.1 选对类型

| 类型 | 金额怎么填 | 例子 |
|---|---|---|
| 补款 | 实际补给客户的钱 | 补 5 元差价 |
| 返现 | 实际转给客户的现金 | 售后补偿 10 元 |
| 补发 | 商品成本 + 快递费 | 破损补发一件 |
| 仅退款 | 退款带来的额外损失：退货运费、包装、卖不掉的货损 | 客户仅退款，货没退回 |
| 退货退款 | 退回运费 + 货损 + 重新包装 | 退回的衣服有污渍 |
| 其他 | 实际支出，写清备注 | 赔偿、平台罚款等 |

### 5.2 三个习惯

- **金额先填，订单号后补**：客户还在等，别为了找订单号卡住。
- **随手传凭证**：转账截图、补发快递单，月底对账有据可查。
- **当天清零待办**：工单列表里"待处理"的置顶，处理完改成"已结算"。

### 5.3 补发会自动扣库存

补发工单提交后，对应商品的可用数量自动减一。库存低于你设的提醒值时，首页会提示补货。

## 六、每周怎么用：老板录费用

### 6.1 录推广费

进入「费用」→「推广费」，按推广计划或链接录入本周花费。

- 知道是哪个计划花的，就记到对应链接；
- 说不清具体链接的，记到店铺，月底统一分摊。

### 6.2 看链接利润

打开「利润」→ 选本周，按链接排序。重点看两个数：

- **贡献利润为负的链接**：卖得越多亏得越多，考虑提价、降推广或下架。
- **售后成本率高的链接**：退货、补发特别多，去查质量或详情页描述。

## 七、每月怎么用：出利润表

### 7.1 补齐三样数据

1. 导入本月订单（平台后台导出）。
2. 录完本月推广费。
3. 录入固定费用：人工、房租、软件、包装耗材。

### 7.2 生成利润表

「利润」→ 选月份 → 生成。报表按订单、链接、店铺三个层级展示：

| 层级 | 回答的问题 |
|---|---|
| 订单贡献利润 | 这一单赚不赚 |
| 链接贡献利润 | 这个款扣掉推广费后赚不赚 |
| 店铺净利润 | 这个月扣掉人工房租后赚不赚 |

每层都能看到：收入、商品成本、快递、平台扣费、售后成本、推广费、利润、利润率。

### 7.3 看懂一张利润表

| 项目 | 金额 |
|---|---:|
| 实收 | 100 |
| 商品成本 | 40 |
| 快递费 | 5 |
| 平台扣费 | 3 |
| 返现 | 5 |
| 补发成本 | 10 |
| **订单贡献利润** | **37** |
| 分摊推广费 | 8 |
| **链接贡献利润** | **29** |

两个口径要记住：

- **退款不会扣两次**：平台退的钱已经在收入里减掉，工单只记退款带来的额外损失（退货运费、包装、货损）。
- **推广费是分摊的**：报表会标"分摊后"，并显示按什么规则摊的，不假装精确到每一单。

### 7.4 看数据完整度

报表顶部会提示：

- "12 个订单未匹配成本"——去补商品成本价；
- "本月推广费未录入"——链接利润还没扣推广；
- "5 笔平台退款未匹配订单"——去核对订单号；
- "3 笔工单待处理"——提醒客服结算。

提示清零后再看利润，数字才可信。

### 7.5 导出和复盘

利润表可导出 Excel/PDF，发给合伙人或存档。月底复盘只看三件事：

1. 哪个链接亏钱，为什么；
2. 哪个链接售后成本异常，去查原因；
3. 推广费和利润的比例是否合理。

## 八、多账号怎么配合

| 角色 | 能做什么 |
|---|---|
| 管理员（老板） | 看所有店铺和报表，管账号、改设置 |
| 客服 | 记工单、看自己店铺的工单 |
| 只读 | 只看报表，不能改数据 |

客服在电脑上记，老板在电脑上看，不用再靠微信对账。

## 九、常见问题

**Q：需要申请平台接口吗？**
不需要。平台后台导出的订单表直接导入就能算。

**Q：能和打单软件一起用吗？**
可以。订单只用于算账，发货打单继续用原来的软件。

**Q：客服不愿意记怎么办？**
一个快捷键、选类型、填金额、提交，10 秒完成；订单号可以后补；月底还能从售后明细批量导入补齐。

**Q：手机上能用吗？**
目前是 Windows 桌面端，后续会推出手机 App。临时在手机上处理售后，可以先用电脑或稍后补记。

**Q：算出来的数准吗？**
取决于你录入的成本和费用。报表会标出哪些数据缺失，数据不全时不糊弄你。

**Q：数据能导出吗？**
订单、工单、费用和利润报表都能导出。
